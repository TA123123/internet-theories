> 2026 年秋天，抖音上刮起一阵"××理论"风：一只手拎起两升装的大水瓶，配文"弱者喝饮料，强者喝大水"，随后"薄肌理论""大睡理论"接连出圈，演化成一整套年轻人的极简健康生活方式。
>
> 本仓库把这类"一个口号 + 一套生活方式"的流行理论搜集、整理成可检索的文档——**每一篇都还原它的出处、核心主张、实践方法，以及热闹之外的理性提醒。**
