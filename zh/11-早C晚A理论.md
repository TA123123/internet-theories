# 早C晚A理论

> English: [The Morning-C Evening-A Theory](../en/11-the-morning-c-evening-a-theory.md)

> 早上维 C，晚上维 A 类护肤，科学护肤，保持年轻状态。

## 一句话概括

早上用维生素 C 抗氧化，晚上用维生素 A（A 醇/视黄醇）抗老——被称为护肤的"黄金公式"。

## 科学原理

- **早 C（维生素 C / 抗坏血酸）**：白天是皮肤遭遇紫外线和自由基的高峰期，维 C 作为抗氧化剂牺牲自己中和自由基，减轻光损伤，并辅助提亮。
- **晚 A（视黄醇 / A 醇）**：促进角质代谢和胶原生成，是证据最充分的抗老成分之一；但它光不稳定、见光易分解失效，且初期有刺激性，适合夜间使用并配合次日严格防晒。
- 两者协同：白天"防御"，晚上"修复"，顺应皮肤的昼夜节律。

## 正确用法

1. **从低浓度开始**：维 C 5%～10% 起步；A 醇从 0.1% 左右的低频次（每周 2 次）开始建立耐受。
2. **顺序**：洁面 → 爽肤水 → 维 C（早上）/ A 醇（晚上）→ 保湿 → 防晒（早上）。
3. **防晒是前提**：不防晒，一切抗老免谈；维 A 类产品期间尤其要严格防晒。
4. **保存**：维 C 易氧化变色，选棕色瓶、避光、尽快用完。
5. **不能颠倒的例外**：敏感肌、屏障受损期先修护；维 A 类孕期禁用（哺乳期遵医嘱）。

## 皮肤科医生的提醒

- 别盲目叠加高浓度、多活性物（多重刺激容易烂脸）。
- 出现持续泛红、脱皮、刺痛，停用并修护，不要"坚持就是胜利"。
- "早 C 晚 A"是流行公式不是万能模板，烟酰胺、胜肽、果酸等成分各有位置。
