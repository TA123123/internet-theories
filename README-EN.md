> In autumn 2026, a wave of "×× theory" memes swept Chinese Douyin: a hand lifting a two-liter bottle of plain water with the caption "the weak drink soda, the strong drink big water". "Lean muscle theory" and "big sleep theory" quickly followed, evolving into a full minimalist-health lifestyle playbook for young Chinese.
>
> This repo collects these "one slogan + one lifestyle" theories into searchable documents — **each one restoring where it came from, what it claims, how to practice it, and the caveats behind the hype.**

<details>
<summary><b>⚠️ Notes & disclaimer</b></summary>

- Content is compiled from public news reports, encyclopedia entries and practitioner sharing. Research date: **October 12, 2026**.
- Some "theories" (e.g. big water, lean muscle) are **internet-derived pop concepts**, not rigorous scientific terms; the docs try to separate viral narrative from scientific consensus.
- Health- and investment-related entries are for information only, **not medical or investment advice**.
- On the repo name: GitHub repository names only allow ASCII characters (non-ASCII gets sanitized, e.g. "互联网理论" → "-"), so the repo uses the English name `internet-theories`. Its subject is "互联网理论".
